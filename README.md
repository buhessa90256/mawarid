# موارد

تطبيق موارد بشرية بسيط بواجهة عربية (RTL) ونظام صلاحيات RBAC.

يعمل على الحاسوب والجوال، بدون إطار ثقيل: PHP + PDO مع SQLite افتراضياً أو MySQL للاستضافة.

## التشغيل السريع

المتطلب: PHP 8.1+ مع امتداد `pdo_sqlite`.

```bash
cd mawarid
php -S localhost:8080
```

ثم افتح:

1. [http://localhost:8080/install.php](http://localhost:8080/install.php) واضغط «تثبيت الآن»
2. [http://localhost:8080/login.php](http://localhost:8080/login.php)

## حسابات التجربة

كلمة المرور الموحدة: `Admin@123`

| البريد | الدور |
|---|---|
| admin@mawarid.local | مدير النظام |
| hr@mawarid.local | مدير موارد بشرية |
| manager@mawarid.local | مدير قسم التقنية |
| staff@mawarid.local | موظفة |

## الصلاحيات

الأدوار مربوطة بجدول `roles` و`permissions` و`role_permissions`. إخفاء الأزرار في الواجهة لا يكفي؛ كل عملية كتابة تُفحص في الخادم.

- مدير النظام: كل شيء بما فيه المستخدمون.
- مدير موارد بشرية: الموظفون، الأقسام، الإجازات، الحضور. لا يدير حسابات مديري النظام.
- مدير قسم: يرى ويعتمد إجازات وحضور قسمه فقط.
- موظف: ملفه، طلب إجازة، حضوره ورصيد إجازته.

للتحقق من الحماية: ادخل بحساب `staff@mawarid.local` ثم أرسل يدوياً طلب حذف موظف. سيُرفض في الخادم حتى لو صُنعت الاستمارة يدوياً.

## الرفع على استضافة MySQL

1. أنشئ قاعدة بيانات.
2. عدّل `config.php`:

```php
'driver' => 'mysql',
'mysql' => [
  'host' => 'localhost',
  'name' => 'اسم_القاعدة',
  'user' => 'المستخدم',
  'pass' => 'كلمة_المرور',
  'charset' => 'utf8mb4',
],
```

3. ارفع المجلد وافتح `install.php` مرة واحدة.

## النطاق

النسخة الأولى تشمل: الدخول، اللوحة، الأقسام، الموظفين، الإجازات، الحضور، المستخدمين.

خارج النطاق: الرواتب المعقدة، البصمة، التكامل الحكومي، تقييم الأداء، التوظيف، تعدد الشركات.
